| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability in CosmicGATE NFT Prediction Stake, please report it responsibly:

1. **Do NOT open a public issue.**
2. Report via [GitHub Security Advisories](https://github.com/md5sha1/CosmicGATE-SOL/security/advisories/new).
3. Include a detailed description of the vulnerability and steps to reproduce.

We will acknowledge receipt within 48 hours and aim to provide a fix within 7 days for critical issues.

## Scope

The following are in scope:
- Solana program (smart contract) vulnerabilities
- Logic bugs in staking, reward distribution, or NFT freeze/thaw
- Access control bypasses
- Integer overflow/underflow issues
- PDA seed collision vulnerabilities
